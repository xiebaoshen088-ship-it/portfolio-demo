## 首屏和详情

- 移除首页数据模块中的五个内联大截图。弹窗代码仅在第一次打开详情时加载，各截图再分别按需加载。
- 曾加载失败的四个话题截图与投票截图仍使用内嵌图像数据，但分散在小型延迟模块中；测试故意阻断独立图片 URL，详情及嵌套读图仍可显示全部五张图片。
- 使用单个延迟 `DialogHost`，避免首次打开嵌套读图时再次挂起、隐藏和重新展开父弹窗。
- 首屏海报高优先级预加载，照片、项目封面和抖音截图懒加载，并标注固有尺寸。
- 原有三种字体改为同站 WOFF2，`font-display: swap`；删除三份外部阻塞字体 CSS，请求不再依赖外部字体站。
- 减少动态效果模式首次进入时只显示海报，不下载视频；手机和节省流量模式使用较小的 60 fps 视频。

## WebGL、滚动和 GSAP

WebGL 实际只覆盖导航条，不是整页动态背景。保留 DPR 1、最多 1536 px 宽的 FBO、2 次材质采样、低功耗上下文和开场后空闲加载。装饰性玻璃反射最多刷新 30 fps，主视频仍为 60 fps。

缓存视频文档坐标和导航几何，仅在尺寸、首屏变换变化时重新测量。滚动采用被动监听与单个 rAF 合并；移除滚动后 480 ms 的额外渲染尾巴，以及每个 WebGL 帧的两次 `getBoundingClientRect()` 和重复 DOM 查询。离开视频区域后静止的玻璃无需持续渲染；弹窗和隐藏页面停止绘制与视频帧回调。

使用 `compileAsync` 和 `KHR_parallel_shader_compile`，编译完成前保留 CSS 材质；不支持该扩展时使用 CSS 材质。原本全白的环境光改成等价的常量 CubeUV 贴图，避免首帧生成 PMREM 及额外模糊着色器。手机、触控、节省流量、低速连接和辅助视觉偏好跳过这层可选 WebGL。

导航原有缓存测量、被动滚动监听、rAF 合并与状态变更时才更新 React 的方式保留。GSAP 仅有 9 个组触发器，缓存固定的动画目标，离开组后重置回放，动画完成后撤销 `will-change`。多次回访、减弱动画切换和尺寸变化均不会累积触发器，键盘焦点可直接揭示内容。
