# 解宝珅 · 运营作品集

React + Vite 单页作品集。五个模块：全屏首页、个人经历、精选项目、个人优势、全屏联系收尾。版心最大 1700px，当前阶段以电脑端为设计和验收范围。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```bash
npm install
npm run dev
```

打开终端中显示的 `http://127.0.0.1:4307/`。

```bash
npm run build
npm run preview
```

## 后续修改

- `src/App.jsx`：五个模块的页面结构。
- `src/data.js`：项目、能力、联系方式和截图的统计口径说明。
- `src/styles.css`：浅色主题、1700px 版心、液态玻璃和响应式布局。
- `src/HeroVideo.jsx`：双视频层交叉淡入，掩盖循环交界；离屏、切换标签页或减少动态效果时暂停。
- `src/Dialog.jsx`：项目从点击位置展开/收回，截图放大，键盘关闭和焦点返回。
- `src/useGlass.js`：玻璃控件的边缘折射；不支持该效果时保留 CSS 玻璃样式。
- `src/GlassStudio.jsx`：顶部「外观」入口，面板从按钮连续展开，位置、圆角、底色、背景模糊与阴影同步变化，快速反向操作从当前动画状态继续。
- `src/OpticalScene.jsx`：受控背景中的 WebGL 玻璃透镜；拖动控件时按实际位置采样背景。
- `src/SegmentedControl.jsx`：导航、材质、配色、背景和平台切换共用的连续选中块，支持方向键。
- `src/EvidenceStack.jsx`：原创话题卡片的堆叠、展开与收起。
- `src/glassConfig.js` 与 `src/liquid-glass.css`：光学、模糊、透光、光源、反馈与展开时长的集中参数。
- `public/assets/`：已有截图、60fps 首页视频和简历。个人照片暂时占位，之后可替换经历区。

数据使用概数，原图保留后台原值。账号整体结果、话题结果和个人分工分开展示。拓竹项目保留成品入口，详细分工与材料待补充。

现有 Sites 项目身份保留在 `.openai/hosting.json`。`dist/` 为 Vite 构建输出，发布前先运行构建。

## 体验这次的玻璃交互

1. 点击右上角「外观」，切换清透/柔和、浅色/深色。
2. 拖动「透光程度」滑块，数值、页面材质和透镜外观同步变化。
3. 更换影像、色块或后台截图，按住透镜拖动；也可用左右方向键移动。
4. 在「精选项目」打开原创话题，展开/收起堆叠卡片；展开后可放大原图。
5. 外观面板可再次点击入口或按 Escape 收回；项目详情与原图也支持 Escape 和焦点返回。

## 真实实现与近似实现

- **受控背景中的真实像素位移**：WebGL 从同一张背景纹理采样；中心保持原坐标，只有圆角边缘改变采样坐标。高光、染色、模糊与内阴影在材质层处理，文字属于独立 DOM 前景。它是实时采样效果，未宣称物理级光线追踪。
- **通用控件的浏览器增强**：Chromium 中的 SVG 位移滤镜作用于 `backdrop-filter` 的背景输入，而不是文字 DOM。已在桌面 Edge 用条纹背景验证边缘变化和中央稳定。不同浏览器的背景滤镜行为可能不同，保留 CSS 模糊、透明度、窄亮边与阴影作为视觉近似。
- **阅读面板与卡片**：阅读面板使用适度底色和模糊来保证信息清晰；后排卡片用简化材质、位移与缩放表现深度，不叠加多层强模糊。
- **性能与降级**：WebGL 只用于展开的外观面板，分辨率上限为设备像素比1.5；背景纹理缓存，只在背景、尺寸或主题改变时重建，没有持续渲染循环。面板关闭后释放 GPU 资源，WebGL 不可用或上下文丢失时保留 CSS 方案。
- **可访问性**：原生滑块支持触摸和键盘，切换器支持方向键与清晰焦点；`prefers-reduced-motion` 取消位移动画，减少透明度/高对比设置使用稳定底色。

已检查：不同背景、透镜移动后的采样对应、前景清晰、滑块数值、选中块宽度变化、快速反向开关、卡片反向展开，以及 WebGL 上下文丢失的降级。
