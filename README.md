# 解宝珅 · 运营作品集

React + Vite 单页作品集。五个模块：全屏首页、个人经历、精选项目、个人优势、全屏联系收尾。版心最大 1700px，当前阶段以电脑端为设计和验收范围。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```bash
npm install
npm run dev
```

打开终端中显示的 `http://127.0.0.1:4307/`。

```bash
npm run build
npm run preview
```

## 后续修改

- `src/App.jsx`：五个模块的页面结构。
- `src/data.js`：项目、能力、联系方式和截图的统计口径说明。
- `src/styles.css`：浅色主题、1700px 版心、液态玻璃和响应式布局。
- `src/HeroVideo.jsx`：单视频解码；循环衔接与运动补帧离线合成。根据显示刷新节奏选用 60/120fps；离屏、打开项目详情、切换标签页或减少动态效果时暂停。
- `src/Dialog.jsx`：项目从点击位置展开/收回，截图放大，键盘关闭和焦点返回。
- `src/useGlass.js`：玻璃控件的边缘折射；不支持该效果时保留 CSS 玻璃样式。
- 全站固定为清透材质、浅色、100% 透光，没有外观切换入口；`src/glassConfig.js` 集中管理固定参数。
- `GlassStudio.jsx` 与 `OpticalScene.jsx` 为此前实验组件，当前页面不导入、不渲染，不产生 WebGL 开销。
- `src/SegmentedControl.jsx`：导航、材质、配色、背景和平台切换共用的连续选中块，支持方向键。
- `src/EvidenceStack.jsx`：原创话题卡片的堆叠、展开与收起。
- `src/glassConfig.js` 与 `src/liquid-glass.css`：光学、模糊、透光、光源、反馈与展开时长的集中参数。
- `public/assets/`：已有截图、60/120fps 首页视频和简历。个人照片暂时占位，之后可替换经历区。

数据使用概数，原图保留后台原值。账号整体结果、话题结果和个人分工分开展示。拓竹项目保留成品入口，详细分工与材料待补充。

现有 Sites 项目身份保留在 `.openai/hosting.json`。`dist/` 为 Vite 构建输出，发布前先运行构建。

## 当前页面效果

全站固定为清透、浅色、100% 透光；没有外观按钮、调节滑块或模式切换。启动前应用固定设置，刷新与系统深色模式不会改变配色。这里的 100% 沿用原透光滑块参数，保留窄亮边、轻微环境染色和阅读面板的必要底色。

导航、按钮、项目详情和原创话题堆叠交互保留。项目从原位置展开，关闭时收回；截图可放大，Escape 关闭并返回焦点。

导航及视频上的玻璃使用 CSS 近似，静态小控件在 Chromium 中使用 SVG 背景位移增强；文字不参与模糊与位移。阅读面板适度加强底色来保持清晰。原外观面板已移出运行页面，没有实时 WebGL 渲染。

## 本次导航与流畅性调整

首页为横向展开的整条玻璃导航，滚动离开后收拢，返回首页恢复。导航形变期间选中块同步定位，避免重复启动补间。120fps 文件由运动插帧生成，高刷显示器可采用；普通 60Hz 环境使用同画面的 60fps 文件，实际呈现帧数受显示刷新率与浏览器影响。视频放缓约 20%，循环过渡写入素材，避免运行时双解码。滚动位置按动画帧批处理，章节布局只在尺寸改变时读取。大型遮罩取消动态模糊，受控 WebGL 透镜保留。
