# 解宝珅 · 运营作品集

React + Vite 单页作品集。五个模块：全屏首页、个人经历、精选项目、个人优势、全屏联系收尾。版心最大 1700px，当前阶段以电脑端为设计和验收范围。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```bash
npm install
npm run dev
```

打开终端中显示的 `http://127.0.0.1:4307/`。

```bash
npm run build
npm run preview
```

## 后续修改

- `src/App.jsx`：五个模块的页面结构。
- `src/data.js`：项目、能力、联系方式和截图的统计口径说明。
- `src/styles.css`：浅色主题、1700px 版心、液态玻璃和响应式布局。
- `src/HeroVideo.jsx`：双视频层交叉淡入，掩盖循环交界；离屏、切换标签页或减少动态效果时暂停。
- `src/Dialog.jsx`：项目从点击位置展开/收回，截图放大，键盘关闭和焦点返回。
- `src/useGlass.js`：玻璃控件的边缘折射；不支持该效果时保留 CSS 玻璃样式。
- `public/assets/`：已有截图、60fps 首页视频和简历。个人照片暂时占位，之后可替换经历区。

数据使用概数，原图保留后台原值。账号整体结果、话题结果和个人分工分开展示。拓竹项目保留成品入口，详细分工与材料待补充。

现有 Sites 项目身份保留在 `.openai/hosting.json`。`dist/` 为 Vite 构建输出，发布前先运行构建。
